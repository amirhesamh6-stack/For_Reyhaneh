# برای ریحانه‌ی من 💗

این یک سایت عاشقانه‌ی استاتیک برای GitHub Pages است.

## انتشار روی GitHub Pages
1. یک repository جدید در GitHub بساز؛ مثلاً `for-rihane`.
2. فایل `index.html` و پوشه‌ی `assets` را در ریشه‌ی repository بارگذاری کن.
3. در repository وارد `Settings` → `Pages` شو.
4. در بخش `Build and deployment` گزینه‌ی `Deploy from a branch` را انتخاب کن.
5. Branch را روی `main` و پوشه را روی `/(root)` قرار بده و Save کن.
6. پس از چند دقیقه، لینک سایت در همان بخش Pages نمایش داده می‌شود.

راهنمای رسمی: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## نکات مهم
- سایت برای موبایل هم طراحی شده.
- رمزها فقط یک مرحله‌ی سرگرم‌کننده‌اند و امنیت واقعی ندارند؛ کد سایت عمومی است.
- GitHub Pages عمومی است. تصاویر گفت‌وگوها ممکن است اطلاعات خصوصی داشته باشند؛ پیش از انتشار عمومی، مطمئن شو هر دو با انتشارشان راحت هستید.
- پاسخ بخش آینده در این نسخه به‌صورت خودکار برای سازنده ارسال نمی‌شود. ریحانه می‌تواند آن را کپی کرده و برایت بفرستد. برای ارسال مستقیم باید سرویس فرم جداگانه‌ای مثل Formspree یا یک بک‌اند اضافه شود.
- موسیقی با دکمه باز می‌شود و به نتایج جست‌وجوی YouTube می‌رود؛ پخش خودکار ممکن است توسط مرورگر مسدود شود و آهنگ‌ها از داخل سایت میزبانی نمی‌شوند.
